# Анализ работ 1.10.1 для Windows x64

## Что добавлено и исправлено

- При импорте Excel приложение использует выбранный лист и сохранённое правило папки. При расхождении выбранного начала периода с явной датой в шапке появляется замечание, в том числе для текстовой даты вида «1.2.2026».
- Контрольные суммы повторяющихся блоков одного подразделения сверяются с детализацией каждого блока. В аналитике скрытый подтверждённый ноль отличается от пропущенного отчёта. При неполных данных видны состав сопоставимой выборки и границы сравнения.
- Печать анализа изменений включает все отфильтрованные строки в выбранном порядке. Графики, таблицы и CSV учитывают общий период, выбранные работы и подразделения. Уточнены подписи показателей и поведение пользовательской базы сравнения.
- Исправлены возврат фокуса из карточки услуги, положение графика при переключении представлений и значок приложения на панели задач Windows.

## Обновление и ограничения

Перед обновлением сохраните резервную копию SQLite через настройки. В существующей общей базе согласуйте обновление на компьютерах сотрудников. Проверка даты действует при новом импорте. Уже сохранённые отчёты с ошибочно выбранной датой требуют ручной сверки с исходной книгой. Для установки вручную скачайте Windows x64 setup.exe из этого выпуска.
