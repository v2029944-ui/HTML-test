# Анализ работ — Tauri 0.1.6

**Статус:** проект заметок к следующему выпуску. Этот файл сам по себе не означает, что релиз опубликован. Выпуск допускается только после успешного Windows CI на точном коммите, публикации установщика в GitHub Releases и проверки его доступности.

## Что добавлено

- **Восстановление SQLite:** в отдельном SQL-режиме можно выбрать резервную копию, проверить структуру и целостность данных, создать независимый восстановленный файл. При явном подтверждении возможна подготовка восстановления рабочей базы **на следующем запуске**, до открытия SQLite. Перед переключением создаётся отдельная защитная копия; предусмотрен отказ при занятых WAL-файлах, изменённом источнике или недостатке места и аварийный откат.
- **Понятные сообщения:** часть ошибок нативных операций SQL, Excel и SQLite переведена на русский язык с рекомендациями и сохранением ссылок на проблемные ячейки.
- **Лимиты до импорта:** SQL-интерфейс показывает действующие ограничения до выбора файла. Режимы импорта имеют разные лимиты; размер до 100 МиБ относится только к потоковому Rust-импорту.
- **Настройка простых правил Excel в SQL:** выбор формата, периода, даты, листа и года с проверкой текущей ревизии SQLite и изменения исходного XLSX. Сохранение правила не выполняет импорт.
- **Обычный XLSX через Rust:** добавлен ручной нативный импорт таблиц «Работа / Количество / Сумма», с выбором листа, предпросмотром, повторной проверкой, явным разрешением замен и SQLite Online Backup перед изменением существующих отчётов.
- **Более крупные XLSX:** в потоковом Rust-режиме архив до **100 МиБ**, до **15 000 000 ячеек** в книге и до **100 000 строк** на лист; временная SQLite до **4 ГиБ**. Проверки ZIP, разархивации, токенов, заголовков и защита записи сохраняются.
- **SQL-режим:** просмотр подключённой папки Excel без чтения полных книг в браузере, обновление ограниченных SQL-страниц после нативного импорта, возможность выбирать SQL как стартовую страницу. Классический интерфейс сохранён.

## Обновление и ограничения

- **Сделайте отдельную резервную копию SQLite и исходных Excel перед установкой.** Восстановление тестировалось на синтетических данных; не считайте это гарантией восстановления любой повреждённой пользовательской базы. Не подменяйте файл базы вручную при открытой программе.
- **100 МиБ — не общий лимит всех режимов.** Классический обработчик Excel всё ещё ограничен **30 МиБ**; для дополнительных видов отчётов действуют отдельные **30 МиБ XLSX** и **8 МиБ JSON**, а также лимит **10 000 строк данных в отчёте**.
- Автоматический фоновый импорт произвольных обычных XLSX в SQL-режиме не включён: изменение папки обновляет список файлов, сохранение — только после проверки. Расширенные сопоставления столбцов требуют классического интерфейса.
- Классический экран Tauri всё ещё может загружать историю целиком в WebView. Для больших данных используйте отдельный SQL-режим и проверяйте потребление памяти на своих файлах.
- Совместимость с предыдущими экспериментальными версиями и автоматическое восстановление их старых баз не гарантируются. Установщик для Windows x64, фактический канал обновлений и необходимость ручной установки указываются в релизе после проверки подписи.
- Браузерный автономный `index.html` не изменён.

## Проверки, обязательные перед публикацией

- Node.js + Rust unit tests, импорт с лимитами, SQLite и обработка отказов; полный Windows NSIS CI.
- GUI smoke на **установленном Windows-приложении через WebView2**, включая правило XLSX, нативный импорт и восстановление SQLite после перезапуска.
- Проверка уникальности версии `0.1.6` и согласованности `tauri/package.json`, `Cargo.toml`, `tauri.conf.json`.
- Для подписанного релиза — проверка прежнего ключа, присутствия установщика и `.sig`, публикация отдельного GitHub Release с этим списком изменений. Канал `tauri-updates` переключается только после проверки доступности и подписи опубликованного релиза.
