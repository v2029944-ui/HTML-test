# Анализ работ 1.11.0 для Windows x64

## Что добавлено и исправлено

- На странице «Загрузка отчётов» можно выбрать одну книгу Excel или открыть книгу из папки. Оба способа ведут к проверке перед сохранением. У каждого файла в списке есть кнопки «Открыть для проверки» и «Настроить правило». Фоновое обновление папки сохраняет открытый выбор страницы. [#105](https://github.com/v2029944-ui/HTML-test/pull/105)
- Для дня, недели и месяца доступны таблицы с единым списком работ и парами столбцов «Количество / Сумма», а также таблицы с отдельным списком работ для каждого периода. Приложение предлагает распознанную структуру и даёт её изменить. При неоднозначности пользователь выбирает структуру сам. Заголовок «Март 2026» в месячной таблице с единым списком работ задаёт период с 1 по 31 марта. [#107](https://github.com/v2029944-ui/HTML-test/pull/107)
- После проверки Excel видно число обработанных ячеек во всей книге. Оно показано отдельно от числа отчётов и строк работ. [#100](https://github.com/v2029944-ui/HTML-test/pull/100)
- В «Отчётах» видно, куда будут сохранены данные. В разделе «Управление → Базы данных» можно подключиться к общей папке, вернуться к личной базе, сделать копию активной базы SQLite и открыть папку с копией. Перед восстановлением личной базы можно сравнить число отчётов в ней и в проверенной копии. [#106](https://github.com/v2029944-ui/HTML-test/pull/106)
- Перед удалением всех импортированных отчётов приложение показывает выбранную базу и число отчётов к удалению. При открытии окна выделена «Отмена». [#101](https://github.com/v2029944-ui/HTML-test/pull/101)
- В окнах выбора работ и подразделений кнопка «Применить» доступна при прокрутке длинного списка. Уточнены отступы у фильтров и поведение таблиц при изменении размеров окна. [#102](https://github.com/v2029944-ui/HTML-test/pull/102)
- У приложения, установщика, ярлыков и панели задач Windows появился жёлтый значок с диаграммой. Для размера 16 пикселей используется упрощённый рисунок. [#104](https://github.com/v2029944-ui/HTML-test/pull/104)

## Обновление и ограничения

Перед обновлением сохраните резервную копию SQLite в настройках установленной версии. Если сотрудники работают с общей папкой, обновите приложение на каждом компьютере. После переключения между личной и общей базами отчёты остаются в исходной базе. Подтверждённое восстановление личной базы выполняется при следующем запуске приложения.

Права записи в общую папку назначает её администратор. Для автоматического сохранения нужны правило файла и включённый автоимпорт в текущем сеансе. Замены, пересечения периодов и замечания требуют ручной проверки.
