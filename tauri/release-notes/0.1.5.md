# Анализ работ 0.1.5 — актуальная версия Tauri для Windows x64

## Что добавлено
- В отдельном SQL-режиме появились **дополнительные виды отчётов с собственными показателями**: пример трудозатрат и выработки, а также отчёт «план/факт».
- Показатели описываются в `metric-kinds.json`: исходные числовые поля, суммы, единицы измерения и расчётные отношения. Отношения вычисляются по суммарным исходным значениям, а не складываются построчно.
- **Настраиваемый импорт простых XLSX**: `metric-xlsx-profiles.json` задаёт лист Excel, строки заголовков, обязательные колонки и соответствие столбцов показателям. Новый формат такого вида можно добавить через конфигурацию и новую сборку без отдельного парсера.
- В SQL-интерфейсе добавлены выбор XLSX-профиля, диапазона дат, предварительный просмотр с проверками и явное подтверждение сохранения.
- Добавлены примеры отчётов и генератор учебных XLSX в `tauri/examples/`, инструкция `docs/EXTENSIBLE_REPORT_KINDS.md`.

## Надёжность хранения и проверки
- Новые показатели сохраняются в **отдельных таблицах SQLite**; существующие данные по количеству и суммам остаются в прежнем контуре.
- Импорт перепроверяет исходный файл, контрольный отпечаток, даты, профиль, ревизию базы и пересечения перед транзакционной записью. Формулы вместо чисел и некорректные значения отклоняются.
- В репозитории добавлены **офлайн-инструмент проверки восстановления SQLite в новую копию** (`tools/restore_sqlite_copy.py`) и автоматические тесты целостности, включая WAL и запрет перезаписи. Это не восстановление рабочей базы внутри программы.
- Автоматические Node, Rust и Windows/WebView2-тесты проверяют новые показатели, XLSX-импорт, SQLite и совместную работу с предыдущими функциями.

## Обновление и известные ограничения
- Это **актуальный выпуск Tauri 0.1.5 для ручной установки на Windows x64**. Установщик NSIS **не подписан** для Tauri Updater. Канал `tauri-updates` не изменяется: автоматическое онлайн-обновление до 0.1.5 не доступно.
- **Перед установкой сделайте отдельную резервную копию SQLite и исходных Excel**, закройте приложение, установите новый EXE и проверьте знакомые отчёты, группы и итоги. Автоматический перенос данных из экспериментальных версий и обратная совместимость не гарантируются.
- Классический интерфейс сохранён и по-прежнему может загружать историю целиком. Для больших наборов используется отдельный постраничный SQL-режим. Автономный `index.html` не менялся.
- Настраиваемые XLSX-профили поддерживают **простую построчную таблицу**, но не произвольные многослойные заголовки, горизонтальные календарные блоки и пользовательские формулы. Ограничение для дополнительного XLSX — до 10 000 строк и 30 МиБ файла.
- Редактирование схем пока выполняется через конфигурацию и пересборку приложения; визуального конструктора и произвольных внешних плагинов нет. Проверка полноты календарных периодов для новых видов отчётов пока не добавлена.
- **Восстановление SQLite в открытую рабочую базу не реализовано.** Не заменяйте файл базы вручную, пока программа работает. Тестирование выполнено преимущественно на синтетических книгах и базах; рабочие Excel следует проверить отдельно.
