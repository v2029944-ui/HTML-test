# Анализ работ 1.10.0 для Windows x64

## Что добавлено

- Для работы с одной базой на нескольких компьютерах откройте «Настройки → Общая база → Подключить общую папку» и выберите одну и ту же сетевую папку. Отчёты, группы и справочник открываются в привычных разделах приложения. В заголовке виден режим работы, в настройках — путь и состояние связи. Программа запоминает выбор и автоматически проверяет обновления общей базы.
- Таблицы отчётов, аналитики и качества данных получили переход к странице по номеру. Во вкладках подробной аналитики доступны «Итоги и рейтинги» и «Соседние периоды». Уточнены подписи дат и показателей, расположение элементов в узком окне и при увеличенном шрифте.
- Отдельный отчёт или все загруженные отчёты можно удалить после подтверждения без обязательного сохранения копии. Чтобы сохранить возможность восстановления, сначала создайте резервную копию в настройках.

## Обновление и ограничения

- Перед установкой сохраните резервную копию SQLite и закройте программу. Для ручной установки используйте Windows x64 EXE из этого выпуска.
- Для общей базы требуется папка с правами записи. При первом подключении к пустой папке общая база начинается без отчётов. Личные отчёты остаются на прежнем компьютере. Приложение открывает выбранную общую базу и при следующем запуске. В настройках можно сменить общую папку. Возврат к личной базе через интерфейс в этой версии недоступен. При недоступной папке работа с данными приостанавливается до восстановления связи.
- Каждая публикация сохраняет полный снимок. Для больших баз учитывайте свободное место и скорость сети. Если связь пропала во время записи, используйте «Повторить отправку». Когда другой пользователь уже сохранил изменения, проверьте состояние общей базы. При необходимости выберите «Отменить неподтверждённые изменения и обновить», подтвердите отмену и подготовьте операцию заново на свежих данных.
