# Анализ работ 1.6.1 — SQLite как основной экран

## Что добавлено

- **SQLite открывается по умолчанию.** При первом запуске и обновлении с 1.6.0 приложение сразу открывает SQLite и раздел «Аналитика». Предварительно включать SQL в настройках не требуется. Запомненная вкладка импорта Excel классического интерфейса не выбирает стартовый экран.
- **Классический интерфейс остаётся доступным по явному выбору.** Его можно открыть по ссылке из основного экрана. Если отключить запуск SQLite, следующий запуск будет классическим; выбор сохраняется явно и может быть изменён обратно.
- **Недоступность локального хранилища настроек сохраняет запуск SQLite.** Настройка помечается недоступной, основным экраном остаётся SQLite без предварительной загрузки классической истории.
- В эту версию также входят уже находившиеся в main улучшения классических графиков: рейтинг для одного периода, подходящая шкала для неотрицательных и отрицательных значений, компактные подписи сравнения. Они не входили в зафиксированный установщик 1.6.0.

## Что исправлено

- В 1.6.0 отсутствие настройки запуска направляло приложение в классический index.html. Если там запомнился импорт Excel, пользователь снова видел Excel вместо основного SQL-экрана. Теперь отсутствие настройки выбирает SQLite.
- Настройка и стартовая страница согласованы с новым основным экраном. Импорт Excel доступен в разделе «Excel и импорт», открывать классический интерфейс для обычной работы с SQLite не требуется.
- Проверка установленного Windows-приложения покрывает первый SQL-запуск без полной истории и повторный запуск с сохранённой классической вкладкой Excel и отсутствующей настройкой режима.

## Обновление и ограничения

- 1.6.1 — отдельный выпуск; EXE и подпись уже опубликованной 1.6.0 не заменяются. Перед установкой сохраните резервную копию SQLite и исходных Excel, закройте приложение.
- Исправление маршрута запуска не удаляет отчёты, настройки или исходные книги и не включает автоимпорт без разрешения. Схема SQLite в этом исправлении не меняется. Автономный браузерный index.html сохранён.
- Онлайн-обновление доступно подписанным установкам с ключом Tauri Updater после проверки и публикации канала 1.6.1. Неподписанные сборки без ключа требуют ручной установки подписанного EXE.
- Проверки используют синтетические контрольные данные; реальные рабочие книги пользователя не предоставлялись. Оставшиеся задачи классического календаря и прокрутки описаны в issues #64/#67 и PR #65.
