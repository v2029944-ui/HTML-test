# Анализ работ 1.5.1 — SQL-интерфейс и подписанные обновления

## Что добавлено

- **Переключаемый запуск SQL-режима.** В отдельном SQL-интерфейсе можно включить «Открывать SQL-режим при запуске программы». При следующем запуске Tauri открывает постраничный SQLite-интерфейс без предварительной загрузки всей истории в JavaScript. По умолчанию сохранён привычный интерфейс.
- **Панель «Папка Excel» в SQL-режиме.** Показывает выбранную папку, названия XLSX, размер и наличие правила, отображая не более 100 файлов одновременно. При изменениях папки список обновляется; новые файлы не импортируются автоматически.
- **Выбор источника Excel.** При смене папки приложение предупреждает о сбросе правил прежнего каталога. Ранее сохранённые отчёты в SQLite при этом остаются.
- **Подписанный установщик Windows x64 и встроенные обновления.** Проверка новой версии, показ изменений, подтверждение установки и проверка криптографической подписи рассчитаны на выпуски с постоянной парой ключей.

## Что исправлено и улучшено

- После успешного нативного импорта широкого XLSX SQL-экран обновляет сводку и ограниченные страницы данных, не загружая всю историю отчётов в WebView.
- SQL-интерфейс сохраняет переход в классические отчёты и импорт Excel, поэтому пока не перенесённые функции остаются доступны.
- Лёгкая стартовая страница Tauri отделена от автономного `index.html`; браузерная версия в репозитории сохранена.

## Обновление и ограничения

- **Первый переход с 0.1.5 на 1.5.1 требует ручной установки:** версия 0.1.5 была выпущена без подписи для Tauri Updater. Скачайте и установите подписанную 1.5.1 из этого GitHub Release. Последующие подписанные версии с прежним ключом могут обновляться из приложения.
- Перед установкой закройте программу и сделайте резервную копию `reports.sqlite3` и исходных Excel. Не заменяйте рабочую SQLite при запущенной программе. Автоматический перенос данных из старых экспериментальных форматов не гарантируется.
- В этом выпуске использованы **только уже объединённые изменения основной ветки**. Незавершённые PR #49 (настройка правил), #51 (нативный импорт обычных XLSX) и #54 (увеличение лимитов Rust до 15 млн ячеек) **не включены**.
- Классический интерфейс по-прежнему может загружать историю в память. SQL-режим ещё не покрывает все графики, настройки и варианты импорта.
- Лимиты загрузки XLSX не изменены. Автоматическая фоновая перезапись отчётов не включена.
- Онлайн-обновления станут доступны только после публикации подписанного установщика и проверки `tauri-updates`. До этой проверки наличие кнопки обновления в интерфейсе не подтверждает готовности сервиса.
