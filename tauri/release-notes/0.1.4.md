# Анализ работ 0.1.4 — Tauri для Windows

## Что добавлено
- Отдельный режим работы с SQLite: постраничный просмотр отчётов и групп без загрузки полной истории отчётов в JavaScript.
- SQL-аналитика по дням, неделям и месяцам: полнота периодов, пропуски, сумма, количество, среднее и замечания качества данных.
- Сравнение подразделений, расшифровка по группам и работам, диаграммы и постраничная навигация.
- Нативный экспорт рассчитанных результатов в CSV с защитой от перезаписи существующего файла.
- Ручной импорт широких ежедневных таблиц XLSX через Rust с предпросмотром дат, предупреждений и адресов ошибочных ячеек.
- Отдельное резервное копирование SQLite, включающее актуальные данные WAL. При замене существующих отчётов Rust требует сначала создать проверенную резервную копию.

## Исправления и безопасность
- Повторная проверка исходного Excel, ревизии базы и конфликтов перед атомарной записью.
- Предотвращение незаметной замены существующих CSV и SQLite-копий.
- Неполные периоды отображаются без ложных нулевых финансовых итогов.
- Автоматические Windows-тесты установки, WebView2, импорта, SQLite и восстановления состояния приложения после перезапуска.

## Обновление и ограничения
- Это **предварительное расширение Tauri**, а не полный перенос старого интерфейса. Обычный запуск всё ещё открывает классический режим; отдельный SQL-режим доступен из постраничного просмотра.
- В новом режиме поддерживается ручной импорт **широкой ежедневной XLSX-таблицы**. Автоматическое обновление папки, другие варианты Excel, все графики и настройки пока доступны через классический интерфейс.
- Классический режим по-прежнему может загружать историю в память. Для большой базы используйте отдельный SQL-режим.
- Создание резервной копии предусмотрено, но **восстановление SQLite внутри работающего приложения ещё не реализовано**. Не заменяйте открытую базу вручную.
- Приложение находится в разработке; совместимость и перенос данных из 0.1.3 в 0.1.4 не гарантируются и не являются условием выпуска. Перед экспериментами с важными данными сохраните отдельную копию SQLite. Исходный самостоятельный `index.html` сохранён.
- Публикация этой версии возможна только после успешного Windows CI на итоговом коммите, проверки резервного копирования и целостности данных, а также явного разрешения владельца. До публикации GitHub Release эти заметки описывают **кандидат**, а не доступный для установки выпуск.
