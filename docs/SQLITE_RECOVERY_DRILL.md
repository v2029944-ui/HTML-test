# Репетиция восстановления SQLite на отдельной копии

**Статус:** инструмент проверки резервного файла перед выпуском Tauri 0.1.4. Это **не** замена активной базы внутри приложения. Утилита не изменяет исходную SQLite и не перезаписывает существующий файл назначения.

## Использование

Требуется Python 3.12. Из корня репозитория:

```powershell
python tools/restore_sqlite_copy.py "D:\Backups\analiz-backup.sqlite3" "D:\Backups\restore-check.sqlite3"
```

Первый путь — существующая резервная копия SQLite, второй — **новый** файл в уже существующем каталоге. Если путь занят, восстановление отменяется. Созданный файл предназначен для проверки **в отдельной папке**; не переименовывайте его в рабочую `Документы\Анализ работ\reports.sqlite3` при запущенном Tauri.

Программа проверяет `PRAGMA quick_check`, наличие таблиц `reports` и `kv` и корректность JSON. Через SQLite Online Backup создаётся консистентная копия, включая данные WAL. Проверяется SHA-256 схемы, отчётов и настроек на одном снимке до/после копирования. Временный файл переводится в самостоятельную базу без WAL и публикуется через жёсткую ссылку без перезаписи. При ошибке временные файлы удаляются. На томах без поддержки жёстких ссылок операция завершается отказом.

SQLite Online Backup переносит **все** таблицы, однако логический хеш проверяет только схему, отчёты и настройки; это не полная проверка аналитических значений остальных таблиц. Для них необходимы функциональные проверки приложения.

## Проверки надёжности восстановления

Python-тесты проверяют незавершённый WAL, BLOB JSON, дополнительные таблицы, отказ от перезаписи, повреждённые файлы и очистку временного хранилища. Они не зависят от версии предыдущего установщика.

```powershell
python -m unittest discover -s tests -p test_sqlite_restore_copy.py -v
```

Это проверка на синтетических данных. Она **не доказывает** восстановление произвольной базы или полноту аналитических итогов. При необходимости восстановления рабочей базы требуется отдельная безопасная процедура при закрытом приложении; прямую замену открытой SQLite не выполнять.

Совместимость установщика и миграция данных с 0.1.3 **не являются условиями выпуска**: приложение пока разрабатывается. Для новых данных остаются обязательными проверки целостности и отсутствие потери информации при сбоях.
