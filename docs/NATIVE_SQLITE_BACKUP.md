# Резервная копия SQLite в Tauri

В «Управление → Базы данных» можно сохранить копию активной личной или общей базы. Кнопка уточняет выбранную базу: «Сохранить копию личной базы» либо «Сохранить копию общей базы». Rust использует SQLite Online Backup API, затем проверяет созданный снимок. Копия включает все таблицы SQLite: отчёты, настройки, диагностические данные и служебные записи, в том числе изменения из WAL.

## Создание копии

Выберите **новый** файл `.sqlite3` через диалог сохранения. Снимок создаётся во временном файле той же папки, проверяется через `PRAGMA quick_check` и чтение ревизии, синхронизируется на диск и публикуется через атомарную жёсткую ссылку. **Существующие файлы не перезаписываются.** При ошибке источник не меняется; приложение пытается удалить временный файл. Для публикации требуется файловая система с поддержкой hard links, например NTFS.

Реализация: [database-backups.js](../tauri/database-backups.js), [database/backup.rs](../tauri/src-tauri/src/database/backup.rs). Сохранение общей базы проходит через выбранную рабочую область; копию SQLite и снимки синхронизации общей папки следует различать. Порядок работы с общей папкой описан в [инструкции Tauri](../tauri/README.md#общая-база-сотрудников).

## Восстановление

В том же разделе доступно **восстановление личной базы**: «Проверить файл копии…» → сверить число отчётов → «Восстановить при следующем запуске» → подтвердить замену. Подтверждение относится также к группам, справочнику и настройкам из копии. Пока приложение не перезапущено, запланированное восстановление можно отменить.

Подготовка не заменяет активную SQLite. При следующем запуске приложение повторно проверяет подготовленную копию, создаёт защитную копию текущей базы и только затем выполняет переключение. Нельзя вручную заменять открытую `reports.sqlite3`. Подробный порядок, ограничения и отдельная утилита проверки — в [SQLITE_RECOVERY_DRILL.md](SQLITE_RECOVERY_DRILL.md).

## Проверки

Проверки копирования и отказа от перезаписи находятся в [backup.rs](../tauri/src-tauri/src/database/backup.rs); проверки восстановления и прерываний — в [recovery.rs](../tauri/src-tauri/src/database/recovery.rs) и [activation.rs](../tauri/src-tauri/src/database/activation.rs). Поведение кнопок и смены рабочей области проверяет [database-backups.test.cjs](../tauri/tests/database-backups.test.cjs). Перед выпуском требуются результаты соответствующих Rust/Node и Windows/WebView2 проверок на точном SHA по [правилам выпуска](RELEASE_POLICY.md); этот перечень не является отчётом об их прохождении.
