# Карта переноса «Анализ работ»

Эталон — предоставленный `analiz-rabot.html`. Первичный обход выполнен в Chromium с его демонстрационными данными. Карта составлена до изменений приложения. Версия настольного продукта 1.8.0 использует Tauri 2. Пользовательские значения на экранах поступают из SQLite. Место в таблице означает назначение переноса. Подтверждение на установленной сборке учитывается отдельно.

| Раздел эталона | Действия и состояния | Место в настольном приложении |
|---|---|---|
| Шапка | Сводка, Анализ изменений, Импорт Excel, Данные, Настройки | Общая шапка. Счётчик отчётов и состояние открытия SQLite |
| Периоды и фильтры | Свернуть и развернуть, день/неделя/месяц/год, один период/диапазон, предыдущий равный интервал, прошлая неделя, прошлый месяц, год назад, своя база. Календарь начала/конца/базы с выбором года, месяца, дня. Сдвиг и пять быстрых периодов, сброс | Общая область выбора, календарь с черновиком. Сохранить отдельный тип источника для агрегированных отчётов |
| Выбор подразделений и работ | Фильтр, поиск, отметить/снять, применить. Отмена и Esc сохраняют прежний выбор | Общая область выбора и постраничный каталог SQLite. Работы ограничивают детализацию |
| Сводка | Три KPI, частичный итог и сопоставимая выборка, состав выборки, таблица подразделений с долями, переход в изменения, крупнейшие вклады, CSV, печать | Сводка. Результаты сравнения и итоги подразделений SQLite, включая явные нули и пропуски |
| Проверка отчётов | Окно текущей/базовой матрицы, страницы по датам, неподтверждённые наблюдения | Матрица из #82, доказательства из #84 и #85, ссылки на отчёты |
| Анализ изменений | Рост/снижение/новые/без выполнений, лидер, выбор суммы/объёма, пороги, справка, поиск, сортировка, все/значимые, постраничная таблица, CSV, печать | Экран изменений по двум общим интервалам. Предыдущий анализ соседних периодов доступен в исходном рабочем представлении |
| Подробная аналитика → Динамика | Работы или подразделения, показатели, графики, подсказки, таблица и CSV | chartPanel, SVG и таблицы SQL. Вертикальная и горизонтальная ориентация из #77 |
| Состав работ | База/текущий, показатель, доля, лимит и выбор работ | structurePanel и локальный сброс на общий период |
| Сравнение | Один период/диапазоны, таблица, вклады, переход на сопоставимую выборку | comparison и contributions, пустое сравнение из #83 |
| Отклонения | Окно обычного уровня, пороги, детализация и экспорт | usualPanel |
| Частота | Статус, разрыв, поиск, страницы и экспорт | regularityPanel |
| Управление | Меню Данные, Отчёты, Группы работ, Настройки, Исходный макет, Свернуть | Панель управления и полный рабочий вид с теми же контроллерами SQLite |
| Отчёты | Обычный XLSX, дневные колонки квартала/года, листы, тип и дата периода, автоматическое/ручное сопоставление, проверка и подтверждение | upload, native staging/prepare/apply. Правила папки, предварительный просмотр и подтверждение замены |
| Загруженные отчёты | Список, календарь года/месяца/дня, открыть и закрыть подробности. Фильтры замечаний по источнику, периоду, подразделению и типу | uploadedReports, календарь, qualitySummary и qualityTable |
| Группы работ | Создание, поиск, выбор участников, сохранение/сброс, управление составом, поиск конфликтов, постраничная проверка, импорт/экспорт, справочник XLSX | groups, groupAuditPanel, groupCatalog с существующими ограничениями записи |
| Настройки | Тема, палитра, дизайн, размер шрифта, подразделения, управление данными | storage. Резервная копия и восстановление SQLite, обновления, подключение папки, дополнительные показатели |
| Закрытие | В каждом месте нажать кнопку один раз, повторно открыть, проверить фокус, Esc, доступность нижнего экрана и отмену черновика. Для вложенных окон проверить оба уровня | WebView2 установленного приложения. Проверка отдельных кнопок важна даже при общем обработчике |
| Размер и данные | Полные, частичные и пустые данные, узкая ширина, крупный шрифт, печать активного экрана | Проверки установленного приложения и снимки экрана |
