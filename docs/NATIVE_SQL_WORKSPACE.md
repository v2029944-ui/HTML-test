# D4b — отдельный SQL-режим Tauri

Доступен через ссылку в панели постраничного просмотра. Переход в `native-workspace.html` освобождает память предыдущей страницы. Отдельный HTML не включает `index.html`, браузерный разбор XLSX или вызовы полной загрузки истории.

Нативный режим показывает SQL-счётчики отчётов, готовых индексов, групп и каталога, фильтрует типы периодов и показывает 100 заголовков отчётов либо 50 групп за запрос. Отчёты нигде не пересобираются в массив JS. Для групп есть явное переименование с подтверждением: `management_begin_settings`, `SettingsEditor::rename_group`, `management_commit_settings`; SQLite ревизия проверяется атомарно, изменяются только настройки, старые отчёты не переписываются. SQLite i64 handle передаётся строкой, чтобы JS не терял точность.

Вызовы Tauri IPC выполняются через `spawn_blocking` и существующую отслеживаемую JS-обёртку; парсинг настроек проходит нативно, потоково, и не требует полного JSON в браузере.

Ограничения: обычный старт Tauri пока всё ещё открывает старый `index.html` с полной загрузкой истории. Чтобы работать без полных JS-массивов, нужно перейти в отдельный режим. Переименование подразделений (orgNames), импорт/удаление отчётов, сложная аналитика, экспорт, настройки каталога и содержимого групп пока не перенесены. SQL-счётчики не являются финансовой аналитикой. Для боевых данных необходима отдельная проверка обновления, реальной базы и полного сценария резервного копирования. `main` и самостоятельный HTML не изменяются.
