# Статус Tauri 1.5.1 и дальнейшей разработки

**Проверено 19 ноября 2026 года** по [GitHub Release 1.5.1](https://github.com/v2029944-ui/HTML-test/releases/tag/tauri-v1.5.1) (исходный коммит `a7c4522a`), текущему `main` и результатам Windows CI. Наличие функции в `main` **не означает** её присутствия в скачиваемой 1.5.1.

| Возможность | В EXE 1.5.1 | В `main` | Примечание |
| --- | --- | --- | --- |
| SQLite и постраничный SQL-режим | Да | Да | Классический экран всё ещё может загружать полную историю |
| Выбор SQL-режима при запуске | Да | Да | Остаётся переключение на классический интерфейс |
| Проверка и подтверждение подписанных обновлений в классическом режиме | Да | Да | Опубликован манифест `tauri-updates` |
| Обновление из SQL-режима | Да | Подготовлено восстановление в PR синхронизации | В `main` до синхронизации не хватало `native-updates.js` и элементов SQL-экрана |
| Проверка SQLite-копии / восстановление при перезапуске | Да | Да | Откат конкретного импорта ещё не реализован |
| Нативный широкий дневной XLSX | Да | Да | Предпросмотр и подтверждение обязательны |
| Правила источников Excel, редактируемые из SQL-экрана | Нет | Да | Изменения PR #56, после публикации релиза |
| Ручной Rust-импорт обычного XLSX | Нет | Да | Не включён в 1.5.1 |
| Лимит 100 МиБ / 15 млн ячеек для нативного Rust XLSX | Нет | Да | 1.5.1: 30 МиБ / 3 млн ячеек для широкого XLSX; у других режимов собственные ограничения |
| Новые планы графиков/фильтров/календаря | Нет | Ещё не все | [ROADMAP](ROADMAP.md), [UX-план](UX_DATA_IMPLEMENTATION_PLAN.md) |

## Ближайшая последовательность работ

1. Синхронизировать SQL-обновления, версию и документацию `main` с опубликованной 1.5.1, не удаляя Rust-функции из PR #56.
2. Проверить ветку синхронизации через Node/Rust/NSIS и установленный WebView2; лишь затем интегрировать в `main`.
3. Завершить [исправления графиков в PR #45](https://github.com/v2029944-ui/HTML-test/pull/45), P0.4–P0.5 (единицы, названия, ошибки в предпросмотре).
4. Для распространения любых новых функций подготовить **отдельную подписанную версию выше 1.5.1**, с точным changelog и ручной публикацией. Существующий `tauri-v1.5.1` и подписанный канал не изменять до релизного решения.

**Контроль:** исходный `index.html` не модифицировать ради Tauri-скриптов. Не считать PR готовым до успешного CI и проверки на копиях пользовательских данных.
