# Настольная версия для Windows

Это отдельная оболочка Electron для существующего [index.html](../index.html). HTML-приложение **не удалено**: его можно открывать в браузере без установки. Настольная версия запускает тот же интерфейс, но сохраняет отчёты на диск и отслеживает выбранную папку Excel.

## Как получить программу

Для Windows 10/11, 64-bit:

1. В GitHub откройте **Actions → Windows desktop executable**.
2. Выберите успешную сборку основной ветки и скачайте артефакт **Analiz-rabot-Windows-x64**. Внутри ZIP — файл EXE.
3. Распакуйте архив и запустите EXE. Node.js на рабочем компьютере не требуется. Эта сборка не имеет сертификата подписи издателя: Windows может показать предупреждение SmartScreen; проверяйте источник файла перед запуском.

Самостоятельный запуск из исходного кода (Node.js 24):

    npm install
    npm run test:desktop
    npm start

Сборка Windows EXE:

    npm run build:win

Интернет нужен при установке зависимостей и сборке. Готовая программа работает без интернета.

## Первая настройка

1. Откройте вкладку **«Импорт Excel»**. Вверху находится блок «Папка Excel · автоматическое обновление».
2. Нажмите **«Выбрать папку с Excel»**.
3. Для каждого XLSX-файла укажите **тип отчёта** и **дату первого периода**. При необходимости укажите название листа: пустое значение означает автоматический выбор.
4. Нажмите **«Запомнить дату»**. Это требуется один раз для каждого имени файла.
5. Теперь заменяйте или добавляйте XLSX в эту папку. Пока программа открыта, она проверяет изменения примерно раз в три секунды и импортирует файлы после завершения копирования. При следующем запуске проверки повторяются.

Примеры имён, для которых программа предложит дату: Неделя-2026-11-09.xlsx, Месяц-2026-11.xlsx. Для Анализ.xlsx предлагается прежняя исходная дата 19.10.2026 — обязательно сверьте с реальными данными. Предложенную дату всё равно требуется подтвердить.

**Важно:** при нескольких блоках в одном файле периоды рассчитываются последовательно от первой даты. Для произвольного набора дат и нестандартных колонок используйте обычный ручной импорт.

## Хранение данных

Настольная версия создаёт папку **«Анализ работ» внутри системной папки «Документы»**:

- reports.json — отчёты и настройки на диске, вне IndexedDB;
- reports.json.bak — предыдущее содержимое базы перед последней записью;
- desktop-config.json — выбранная папка Excel и правила файлов;
- desktop-config.json.bak — предыдущая конфигурация.

Точный путь показан на экране. Кнопка **«Папка базы данных»** открывает его. Не редактируйте JSON во время работы программы. Для полноценной резервной копии используйте **«Данные и настройки → Скачать резервную копию»** и храните её отдельно. Файл .bak не является полноценной историей версий.

Данные браузерного HTML не переносятся автоматически: скачайте JSON-копию из старого приложения и восстановите её в настольной версии. Восстановление заменяет текущие отчёты и настройки после подтверждения.

## Защита и ограничения

- Автоматически принимаются обычные XLSX до 30 МБ из верхнего уровня выбранной папки (без вложенных каталогов).
- До настройки начальной даты новый файл **не импортируется**.
- Необработанные файлы, пустые блоки, ошибки распознавания и замечания импорта не заменяют ранее сохранённые отчёты. Причина показывается на экране.
- Если другой файл или ручной импорт уже содержит тот же период, автоматическая замена отклоняется. Замена допустима только для данных из того же имени файла.
- Удаление XLSX из папки не удаляет импортированные отчёты автоматически. Ненужные отчёты удаляются в приложении вручную.
- Когда программа закрыта, папка не отслеживается. Сканирование выполняется снова при запуске.
- Специальные схемы колонок и импорт справочника доступны через существующий ручной интерфейс.
- Хранение реализовано с атомарной заменой JSON и резервной копией. Максимальный размер файла базы — 100 МБ. Для многопользовательской работы понадобится другая архитектура.

Сборка EXE выполняется в GitHub Actions при доступном Windows runner. Реальный Excel и нативные диалоги/SmartScreen следует дополнительно проверить на целевой Windows-машине.
